ITEC 101: Introduction to Information Technology

Mr. Seng Theara

Learning Outcome

  • Explain how computers represent numbers, text, images, and other digital data using binary.

  • Convert numbers between decimal, binary, and hexadecimal systems, and encode and decode characters using ASCII.

  • Identify major computer hardware components, including the CPU, GPU, RAM, motherboard, and storage, and describe their functions.

  • Explain how the CPU processes instructions through the fetch–decode–execute cycle and how memory supports processing.

  • Differentiate between RAM, ROM, cache memory, and secondary storage based on their functions and characteristics.

  • Evaluate basic computer performance factors, including processor speed, number of cores, memory capacity, and cooling, to recommend appropriate hardware improvements.
