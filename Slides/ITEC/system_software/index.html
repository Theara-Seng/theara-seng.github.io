Practice

Part A - Create your folders

  • Go to your Desktop using CMD.
  • Create a folder named University.
  • Inside University, create two folders: ITEC101 and Python.
  • Inside ITEC101, create two folders: Assignments and Projects.
  • Display the complete folder structure.

Part B - Create and edit files

  • Create a file named student.txt inside ITEC101 containing your name.
  • Display the contents of student.txt in CMD.
  • Add the text "Welcome to ITEC101" without removing the existing text.
  • Open student.txt using Notepad.
  • Create a file named homework.txt inside Assignments.

Part C - Manage your files

  • Copy student.txt into Projects.
  • Rename the copied file to profile.txt.
  • Move homework.txt from Assignments to Projects.
  • Display all files inside Projects.
  • Delete homework.txt from Projects.
  • Display the final folder structure, including files.
