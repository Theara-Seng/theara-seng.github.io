The Five Basic Computer Operations and Their Hardware

Input Device

  • Used to input data into the computer
  • Keyboards, mice, scanners, cameras, microphones, touch pads, touch screens, fingerprint readers, etc.

The Five Basic Computer Operations and Their Hardware

Processing Devices 

  •  Perform calculations and control computer’s operation
  •  Central processing unit (CPU) and GPU

The Five Basic Computer Operations and Their Hardware

Output Devices 

  • Present results to the user
  • Monitors, printers, speakers, projectors, etc. 

The Five Basic Computer Operations and Their Hardware

Storage Devices 

  •  Used to store data on or access data from storage media
  • Hard drives, CD/DVD discs and drives, USB flash drives, etc. 

The Five Basic Computer Operations and Their Hardware

Communications Devices 

  •  Allow users to communicate with others and to electronically access remote information
  •  Modems, network adapters, routers, etc.
